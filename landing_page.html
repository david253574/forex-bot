Knowledge Base

Technical Architecture FAQ

How does the 4-pair ensemble manage cross-currency correlation?

Rather than running an identical heuristic policy across all pairs, the platform maintains four distinct PyTorch policies trained on isolated distributions. If the US Dollar index rallies, each pair independently evaluates its localized ATR volatility, spread gate, and order-flow liquidity rather than executing correlated trades in lockstep.

What happens to open positions if the server loses internet connectivity?

Because orders are dispatched with atomic server-side brackets, OANDA’s matching engine holds the Stop-Loss and Take-Profit orders directly on their institutional infrastructure. Even if the local daemon process is terminated, open positions are closed by the broker matching engine at specified prices.

Why does the platform prohibit Martingale and grid averaging?

Martingale doubling and unbracketed grid averaging-down produce artificial high win rates while exposing accounts to catastrophic tail-risk liquidation. FOREX AI enforces a strict 1-trade-per-pair maximum with predetermined ATR volatility brackets and a hard daily loss ceiling.

How is the local LLM advisory kept separate from live trade dispatch?

The local LLM advisory service (Ollama DeepSeek-R1) runs in a bounded, non-blocking asynchronous queue with strict timeouts. It functions purely as an explanatory market intelligence stream and has zero execution authority to open orders, modify stop-losses, or adjust position sizing.

How are API credentials secured on multi-tenant servers?

OANDA broker credentials and API tokens are encrypted via AES-128-CBC using individual salted PBKDF2 keys before persistence into the database. Plaintext tokens are never logged or exposed in public API responses.

What are the supported deployment modes?

The platform operates in Practice Sandbox mode by default, interfacing with OANDA v20 practice accounts. Operators can configure custom OANDA API credentials or run simulated paper trading across all four currency corridors.
